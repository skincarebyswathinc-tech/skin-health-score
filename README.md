# Skin Health Score

You are a senior AI product architect and full-stack developer.

Design a micro-SaaS web application called SkinPulse.

Purpose:
The app analyzes a user's selfie and generates skin health metrics and a skin score.

Core features required in Phase 1:

User Account System
Users can sign up, log in, and store scan history.

Selfie Upload Scanner
Users upload a face photo and the system analyzes it.

Skin Analysis Engine
The system analyzes visible skin markers including:

wrinkles
pores
redness
pigmentation
hydration indicators

The system produces numeric scores from 0–100.

Skin Health Score
A weighted score combining the above metrics.

Results Dashboard
Shows:
skin score
skin age estimate
individual metrics

Scan History
Users can see previous scans.

Please produce:

1 Product architecture
2 Feature breakdown
3 Page structure
4 API structure
5 Database schema
6 Frontend components
7 Backend logic
8 AI analysis pipeline

The app should be lightweight, scalable, and micro-SaaS ready.
